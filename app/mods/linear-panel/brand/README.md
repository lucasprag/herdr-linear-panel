# Linear logo

`logo-light.svg` (white, for dark themes) and `logo-dark.svg` (for light
themes) are Linear's logomark, unchanged, from Linear's brand assets
(https://linear.app/brand). Linear and the Linear logo are trademarks of
Linear. They are not covered by this repository's MIT license, and this
project isn't affiliated with or endorsed by Linear.

Use them as they are: show them with `image()` (not `svg()`, which would
recolor them), the white one on dark themes and the dark one on light themes.
